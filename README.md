# QR Code Generator

A lightweight, browser-based QR code generator built with plain HTML, CSS, and JavaScript.

## 🚀 What it does

- Converts any URL into a QR code instantly
- Lets users choose the QR code size
- Displays a download button for saving the generated QR image
- Uses a clean Tailwind CSS layout and the `qrcodejs` library

## 💡 Features

- Fast, client-side generation
- No backend required
- Responsive interface with modern styling
- Downloadable PNG-style QR code image

## 🧪 How to use

1. Open `index.html` in your browser
2. Enter a URL in the input field
3. Choose a size from the dropdown
4. Click **Generate QR Code**
5. Save the generated QR image using the download button

## 📁 Files included

- `index.html` — user interface and page structure
- `script.js` — QR code generation logic
- `README.md` — project overview and usage guide

## 🔧 Built with

- HTML
- JavaScript
- Tailwind CSS (CDN)
- `qrcodejs` library

## ✅ Notes

- The QR generator works entirely in the browser
- If you want to customize the style, edit `index.html`
- If you want to extend the generator, update `script.js`
